# Memory Bank

## Обязательное использование
При каждом запуске новой задачи:
1. Прочитай все файлы из папки `.ai/memory_bank/` для восстановления контекста
2. Используй информацию из memory bank при ответах и принятии решений

## Обязательное обновление
Обновляй файлы memory bank при:
- Завершении значимой задачи
- Обнаружении новой важной информации о проекте
- Изменении архитектуры или технического стека
- Смене текущего фокуса работы

## Файлы memory bank
- `.ai/memory_bank/projectbrief.md` — общее описание проекта (обновляй редко)
- `.ai/memory_bank/productContext.md` — контекст продукта (обновляй при изменении целей)
- `.ai/memory_bank/activeContext.md` — текущий контекст работы (обновляй часто)
- `.ai/memory_bank/systemPatterns.md` — архитектурные паттерны (обновляй при новых открытиях)
- `.ai/memory_bank/techContext.md` — технический контекст (обновляй при изменении стека)
- `.ai/memory_bank/progress.md` — прогресс выполнения задач (обновляй при каждом завершении задачи)
