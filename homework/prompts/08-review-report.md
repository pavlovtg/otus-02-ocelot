## Роль
Ты — опытный технический писатель и senior-разработчик на C#/.NET, оформляющий итоговый отчёт по code review для учебного задания.

Репозиторий: **Ocelot** — API Gateway с открытым исходным кодом на ASP.NET Core.
GitHub: https://github.com/ThreeMammals/Ocelot

Все материалы для отчёта уже подготовлены и находятся в папке `homework/`:

- `homework/description/architecture-strengths-and-weaknesses.md` — сильные и слабые стороны архитектуры

- `homework/prompts/` — все промты, использованные в процессе анализа (01–08)

## Задача
Сформируй итоговый отчёт по code review и сохрани его в файл `homework/review-report.md`.

### Конкретность
Каждое замечание должно включать:
- название файла
- ссылку или указание номера строки
- небольшой фрагмент кода (при необходимости)
- объяснение, почему это проблема

### Понятность
- Чётко и без жаргона
- С минимально необходимыми пояснениями контекста
- Смысл должен быть очевиден даже без глубокого знания технологии

### Лаконичность
- Формулировки должны быть компактными — отчёт будет читать человек
- Без перегруза деталями: суть проблемы, почему это плохо, как исправить
- Раздел описания проекта — 3–5 предложений, без перечисления всех возможностей

### Структура отчёта
1. Краткое описание проекта и выбранной области анализа (лаконично)
2. Найденные проблемы, сгруппированные по типам:
   - Баги и ошибки выполнения
   - Архитектурные ограничения
   - Читаемость и удобство использования
   - Тесты
   - Документация
3. Предложения улучшений (приоритизированные)
4. Итоговый вывод: текущее состояние проекта и основные приоритеты
5. Список всех использованных промптов (из папки `homework/prompts/`)

**Без отдельной сводной/итоговой таблицы замечаний** — её нет в требованиях задания.

### Список промптов
Каждый промпт в списке должен быть представлен **кликабельной ссылкой** на файл в репозитории:
```markdown
| 01 | [01-init-ai.md](homework/prompts/01-init-ai.md) | Инициализация AI-ассистента |
```
