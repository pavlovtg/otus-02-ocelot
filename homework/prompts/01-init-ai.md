## Роль
Ты — разработчик подготавливающий репозиторий для работы с AI ассистентом.

## Контекст
Есть больший репозиторий, в него надо добавить структуры помогающие работать с AI-ассистентом используя Cline

## Задача
1. Создать структуру папок в корне репозитория:
/.ai
/.ai/memory_bank
/.ai/prompts

2. Создать в папке /.ai/prompts базовые шаблоны запросов:
  - Создание запрос к ассистенту в файле в папке /homework/prompts
  - Выполнение операции commit и push в репозиторий;

3. Инициализировать memory bank в папке /.ai/memory_bank через команду "init memory bank in folder /.ai/memory_bank"

4. Создать базовые rules для Cline:
  - Отвечать всегда на русском языке
  - Использовать и обновлять memory bank
