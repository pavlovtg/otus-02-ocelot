## Роль
Ты — разработчик подготавливающий репозиторий для работы с AI ассистентом.

## Контекст
Есть больший репозиторий, в него надо добавить структуры помогающие работать с AI-ассистентом используя Cline

## Задача
1. Создать структуру папок в корне репозитория:
/.ai
/.ai/memory_bank
/.ai/prompts

2. Создать в папке /.ai/prompts базовые шаблоны запросов:
  - `create-prompt.md` — инструкция по созданию нового файла промта в папке `/homework/prompts/`.
    Файл промта именуется по схеме `<index>-<codename>.md`, где:
    - `<index>` — числовой индекс с ведущим нулём, определяется как максимальный существующий индекс в папке + 1
    - `<codename>` — краткое название латиницей через дефис, запрашивается у пользователя
  - `commit-and-push.md` — пошаговая инструкция по выполнению операции commit и push в репозиторий.
    Сообщения коммитов пишутся на русском языке.
  - `code-review.md` — шаблон для проведения code review модуля или набора файлов.
    Должен включать структуру входных данных (файлы, тесты, известные баги) и формат отчёта по категориям.

3. Инициализировать memory bank в папке /.ai/memory_bank через команду "init memory bank in folder /.ai/memory_bank"

4. Создать базовые rules для Cline в папке `.clinerules/` (каждое правило — отдельный файл):
  - `language.md` — отвечать всегда на русском языке, комментарии и сообщения коммитов тоже на русском
  - `memory-bank.md` — использовать и обновлять memory bank при каждой задаче
  - `prompts.md` — сохранять промты в `/homework/prompts/`, использовать шаблоны из `/.ai/prompts/`
  - `code-review.md` — правила проведения code review: баги, архитектура, производительность, читаемость, тесты, безопасность, .NET-специфика (async/await, IDisposable, thread-safety, LINQ, DI и др.)

5. Требование лаконичности: все rules и шаблоны промтов должны быть максимально компактными.
   - Одно предложение вместо абзаца
   - Буллеты вместо развёрнутых описаний
   - Убирать вводные фразы и дублирующие пояснения
   - Цель: экономия токенов контекста без потери смысла
