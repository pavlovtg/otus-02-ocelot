## Роль
Ты — опытный архитектор программного обеспечения, специализирующийся на .NET и паттернах проектирования.

## Контекст
Репозиторий Ocelot — API Gateway на платформе .NET (форк https://github.com/ThreeMammals/Ocelot).
Проект реализует маршрутизацию, аутентификацию, rate limiting, load balancing, service discovery и другие возможности API Gateway.

Подробное описание проекта уже есть в `homework/description/detailed-description.md` — не дублируй его содержимое.

## Задача
Проведи анализ архитектуры проекта Ocelot:
1. Определи архитектурные паттерны и подходы, используемые в проекте
2. Опиши ключевые модули и их взаимодействие
3. Построй архитектурные диаграммы C4 в формате PlantUML:
   - **C4 Context** (уровень системы) — Ocelot в контексте внешних систем и пользователей
   - **C4 Container** (уровень контейнеров) — основные компоненты Ocelot и их взаимодействие
   - **C4 Component** (уровень компонентов) — ключевые модули внутри Ocelot (Routing, Middleware Pipeline, Authentication, Load Balancer и т.д.)

## Входные данные
- Папка: `src/Ocelot/` — основной исходный код
- Папка: `src/Ocelot.Provider.Consul/` — провайдер Consul
- Папка: `src/Ocelot.Provider.Kubernetes/` — провайдер Kubernetes
- Файл: `docs/introduction/bigpicture.rst` — общая архитектура
- Папка: `docs/features/` — описание возможностей
