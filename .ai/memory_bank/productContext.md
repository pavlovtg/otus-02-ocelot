# Product Context

## Зачем существует этот проект?
Ocelot решает задачу единой точки входа для микросервисной архитектуры на .NET. Он позволяет:
- Скрыть внутреннюю структуру сервисов от клиентов
- Централизовать cross-cutting concerns (аутентификация, логирование, rate limiting)
- Упростить управление маршрутизацией

## Целевая аудитория
Разработчики .NET-приложений, строящие микросервисные системы.

## Ключевые проблемы, которые решает
1. Единая точка входа для множества downstream-сервисов
2. Централизованная аутентификация (JWT, Identity Server)
3. Балансировка нагрузки между экземплярами сервисов
4. Ограничение частоты запросов (rate limiting)
5. Service discovery через Consul и Kubernetes

## Контекст использования в учебном задании
