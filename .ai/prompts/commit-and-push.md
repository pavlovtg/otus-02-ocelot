# Шаблон: Commit и Push в репозиторий

## Роль
Ты — разработчик, выполняющий фиксацию изменений в git-репозитории.

## Задача
Выполни commit всех текущих изменений и отправь их в удалённый репозиторий.

## Шаги выполнения

### 1. Проверить статус изменений
```bash
git status
```

### 2. Добавить файлы в индекс
```bash
# Добавить все изменённые файлы
git add .

# Или добавить конкретные файлы
git add <путь/к/файлу>
```

### 3. Создать коммит
```bash
git commit -m "<тип>: <краткое описание изменений>"
```

**Типы коммитов (Conventional Commits):**
- `feat` — новая функциональность
- `fix` — исправление бага
- `docs` — изменения в документации
- `refactor` — рефакторинг кода
- `chore` — вспомогательные задачи (настройка, зависимости)
- `test` — добавление или изменение тестов

**Пример:**
```bash
git commit -m "docs: добавить структуру AI memory bank и правила Cline"
```

### 4. Отправить изменения в удалённый репозиторий
```bash
# Push в текущую ветку
git push

# Push в конкретную ветку
git push origin <имя-ветки>
```

### 5. Проверить результат
```bash
git log --oneline -5
```

## Примечания
- Убедись, что коммит-сообщение написано на русском языке
- Не включай в коммит временные файлы, секреты и credentials
- Проверь `.gitignore` перед выполнением `git add .`
