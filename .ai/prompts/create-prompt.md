# Шаблон: Создание нового промта

## Роль
Ты — разработчик, создающий структурированный промт для AI-ассистента.

## Задача
Создай новый файл промта в папке `/homework/prompts/` по следующей инструкции.

## Шаги выполнения

### 1. Определить индекс файла
Посмотри на существующие файлы в папке `/homework/prompts/`:
```bash
ls homework/prompts/
```
Найди максимальный числовой индекс среди файлов вида `<index>-<codename>.md`.
Новый индекс = максимальный + 1, с ведущим нулём (например: `01`, `02`, `03`...).

### 2. Запросить codename у пользователя
Спроси пользователя:
> Введите codename для нового промта (краткое название латиницей через дефис, например: `code-review`, `analyze-module`):

### 3. Создать файл
Имя файла: `<index>-<codename>.md`
Расположение: `/homework/prompts/`

Пример: `02-code-review.md`

### 4. Структура файла промта

```markdown
## Роль
[Описание роли AI-ассистента]

## Контекст
[Описание контекста: проект, область кода, что уже известно]

## Задача
[Чёткая формулировка задачи]

## Входные данные
- Файл/модуль: [путь или название]
- Дополнительно: [любые данные, необходимые для выполнения]

## Ожидаемый результат
[Что должно быть на выходе: анализ, код, список замечаний и т.д.]

## Ограничения
- [Ограничение 1]
- [Ограничение 2]
```

## Пример готового файла

**Имя:** `02-code-review.md`

```markdown
## Роль
Ты — опытный разработчик на C#/.NET, проводящий code review.

## Контекст
Репозиторий Ocelot — API Gateway на .NET. Анализируем модуль маршрутизации.

## Задача
Проведи code review файла `src/Ocelot/Routing/Router.cs` и найди потенциальные баги,
архитектурные проблемы и нарушения читаемости.

## Входные данные
- Файл: `src/Ocelot/Routing/Router.cs`

## Ожидаемый результат
Список замечаний с указанием номеров строк, описанием проблемы и предложением улучшения.

## Ограничения
- Не предлагать изменения публичного API
```
